Sogolo — Site Plan

A concise project plan for a responsive personal portfolio website.

Site Name

Name: Sogolo

Reason: A personal portfolio and project showcase highlighting design and development work by Sogolo.

Site Purpose

The site provides trail guides, gear recommendations, map links, and an event calendar to help hikers plan safe and enjoyable outings.

User Scenarios

  • How can I view Sogolo's recent projects and case studies?
  • How can I contact Sogolo for freelance work or collaboration?

Color Scheme

Primary
#0b6e4f — headings, buttons
Accent
#f2a900 — accents, highlights

Usage: Use the primary color for prominent headings, CTAs, and navigation highlights. Use the accent color sparingly for badges and callouts.

Typography

Headings: Libre Baskerville (serif) — used for h1/h2 to convey trust and readability.

Body: DM Sans (sans-serif) — used for body text and UI elements for clarity.

Wireframe

Below are simple sketches representing the mobile and desktop home page layout.

CTA

Mobile: stacked, single-column with prominent CTA.

Desktop: left navigation, main content area for maps and featured trail.

Notes & Requirements

  • Pages required: index.html (home), projects.html (portfolio & case studies), about.html (about + contact — form action page separate).
  • Data: Use a local JSON file (projects.json) and fetch it with the Fetch API (include try...catch).
  • Dynamic content: display at least 15 project items with 4+ properties each (title, date, summary, technologies).
  • Local storage: save user preferences (e.g., preferred difficulty filter, sort order).
  • Modal: use accessible modal for trail details (focus trap, aria-hidden toggles).
