# Final Project scaffold

This folder contains a minimal scaffold for the WDD231 final project assignment.

To view the pages locally (Fetch won't work via file://), run a simple HTTP server from the repository root:

```sh
python3 -m http.server 8000
```

Then open:

- http://localhost:8000/final/index.html
- http://localhost:8000/final/projects.html

Next steps (suggested): implement localStorage preferences, add an HTML form and form-action page, optimize images, and run accessibility/lighthouse audits.
